色の表現シミュレーター

コンピュータは色を赤・緑・青の光の強さ（数）で表す

光ひかりの三さん原げん色しょく（赤・緑・青）：光を重ねると、重なったところは明るくなる ＝ 加か法ほう混こん色しょく（混ぜるほど明るい）

光の丸は、指やマウスでドラッグして動かせます

10進しん数すう2進しん数すう（8ビット）…押すと 0 と 1 が入れかわる16進しん数すう

カラーコード＝ # のあとに、赤・緑・青の強さを 16進しん数すう2けたずつならべたもの（00〜FF ＝ 0〜255）。1色＝8ビット → 3色で 24ビット。
